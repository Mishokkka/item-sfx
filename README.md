# Forbidden Lands Item SFX

Минимальный модуль звуков атак для Forbidden Lands.

Поддерживаемые связки:

- Foundry VTT 13 и 14;
- Forbidden Lands 13.0.5 и ветка 14.x;
- предметы типа `weapon`;
- предметы типа `monsterAttack`;
- мировые актёры, синтетические токен-актёры и перенос актёров через компендиумы.

## Что делает модуль

ГМ назначает предмету плейлист и звук. Модуль проигрывает его только тогда, когда сообщение чата является броском атаки и сам бросок однозначно указывает на этот предмет.

Обычные проверки навыков, карточки предметов, RollTable и атаки других предметов звук не запускают.

## Установка

1. Удалить старую папку `Data/modules/fl-item-sfx`.
2. Распаковать папку `fl-item-sfx` из архива в `Data/modules/`.
3. Перезапустить Foundry или мир.
4. Включить `Forbidden Lands Item SFX`.

Существующие `flags.fl-item-sfx.config` и actor backup сохраняются. Данные Maestro не используются.

## Настройка предмета

Кнопка с иконкой громкости находится справа в заголовке листа Item и видна только ГМу.

Можно выбрать:

- один PlaylistSound;
- случайный звук из плейлиста;
- все звуки плейлиста одновременно.

## Инструменты

`Configure Settings → Module Settings → Forbidden Lands Item SFX → Item SFX tools`

- **Восстановить привязки** возвращает отсутствующие настройки из actor backup. Неоднозначные совпадения пропускаются.
- **Пересобрать бэкапы** создаёт actor-level копии настроек embedded Items и переносит однозначно распознанные старые backup-записи в схему v2.
- **Проверить ссылки** проверяет мировые Items, embedded Items и Item Compendiums, считает отсутствующие плейлисты, звуки и неоднозначные бэкапы без изменения документов.

После перехода с 1.x безопасный порядок такой: сначала **Восстановить привязки**, затем **Пересобрать бэкапы**, затем **Проверить ссылки**.

## Как определяется атака

Модуль сначала проверяет данные `ChatMessage.rolls`. Forbidden Lands сохраняет в параметрах броска признаки `isAttack`, `isMonsterAttack`, `itemId`, `item` или `attack`. Разметка сообщения используется только как дополнительный источник после render hook.

Поиск fail-closed:

- необходим явный признак атаки;
- допустимы только точные типы `weapon` и `monsterAttack`;
- при нескольких одинаково вероятных предметах звук не проигрывается;
- наличие настроенного звука не влияет на выбор предмета.

## Сеть и звук

В режимах «первый активный ГМ» и «автор сообщения» один клиент запускает звук локально и рассылает одноразовый SFX через module socket. Получатель проверяет, что файл действительно принадлежит указанному PlaylistSound. Состояние PlaylistSound не изменяется, поэтому модуль не должен вмешиваться в стандартный звук кубиков.

В режиме «все клиенты» каждый клиент играет звук только локально. Повторной сетевой рассылки нет.

## Отладка

Включить `Отладка в консоль`, затем открыть консоль браузера. Основные сообщения:

- `fl-item-sfx | message processing`
- `fl-item-sfx | message analysis`
- `fl-item-sfx | resolved attack item`
- `fl-item-sfx | sound playback`

Проверка версии:

```js
game.flItemSfx.version
```

Ручной аудит:

```js
await game.flItemSfx.audit()
```
